## O que é o Routinely?

O Routinely é uma aplicação web moderna criada para ajudar você a organizar sua rotina semanal, gerenciar tarefas diárias e acompanhar sua produtividade de forma simples, visual e eficiente. Com uma interface intuitiva, o Routinely permite que qualquer pessoa — de estudantes a profissionais — planeje semanas, registre atividades, acompanhe o progresso e mantenha o foco nos objetivos.

---

## Para quem serve?
- **Profissionais** que desejam organizar compromissos e metas semanais
- **Estudantes** que querem planejar estudos e tarefas
- **Empreendedores** que precisam de visão clara das prioridades
- **Qualquer pessoa** que busca mais produtividade e organização

---

## Como usar o Routinely?

1. **Crie sua conta** e faça login na plataforma.
2. **Inicie uma nova semana**: Planeje seu período, defina datas e comece a adicionar atividades.
3. **Adicione tarefas diárias**: Registre compromissos, estudos, hábitos ou qualquer atividade relevante.
4. **Acompanhe seu progresso**: Marque tarefas como concluídas e visualize seu avanço semanal.
5. **Finalize semanas**: Ao concluir um ciclo, finalize a semana e comece o planejamento do próximo período.
6. **Acesse de qualquer lugar**: O Routinely é PWA, podendo ser instalado no seu dispositivo e usado offline.

## Arquitetura e Tecnologias

O Routinely foi desenvolvido com uma arquitetura moderna, focada em performance, escalabilidade e experiência do usuário:

- **Frontend:**
  - React 18 (SPA)
  - TypeScript
  - Vite (build ultra-rápido)
  - Tailwind CSS (design responsivo)
  - shadcn/ui (componentes visuais)
  - Zustand (gerenciamento de estado)
  - TanStack Query (requisições e cache)
  - React Router DOM (navegação)
  - PWA (instalação e uso offline)

- **Backend:**
  - Node.js + TypeScript
  - Fastify (API REST)
  - Prisma ORM
  - PostgreSQL (banco de dados)
  - JWT (autenticação segura)

- **Outros:**
  - Service Worker (cache offline)
  - Web App Manifest (instalação nativa)

> **Nota:** Detalhes técnicos, endpoints e integrações avançadas estão documentados em arquivos específicos na pasta `/doc`.
